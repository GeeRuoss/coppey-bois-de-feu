## Voie la plus simple pour la maquette locale

Avec un abonnement Adobe éligible déjà connecté, ouvrir la [page Stolzl](https://fonts.adobe.com/fonts/stolzl), choisir **Add to Web Project**, créer un projet `Coppey Bois de feu`, sélectionner seulement les styles réellement utilisés puis intégrer le code fourni dans le `<head>`. Reprendre le nom CSS et les poids affichés par le projet, sans inventer de kit ID. Les étapes et la gestion de `font-display` sont documentées par [Adobe](https://helpx.adobe.com/fonts/web/introduction/add-fonts-website.html).

Adobe confirme que le même code d’intégration fonctionne sur un serveur local et même une page ouverte depuis le système de fichiers. [Développement local](https://helpx.adobe.com/fonts/web/web-design-and-development/develop-locally.html)
